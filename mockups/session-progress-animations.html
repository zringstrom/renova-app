All five are now driven by one shared progress value (0→100% per demo cycle, holds briefly at 100%, then resets — standing in for a real phase finishing and the next one starting) instead of looping independent of elapsed time.
Portability: Sweep Bar / Tick March / Scan Line = width/position tied to a `progress` value (trivial in SwiftUI via .frame/.offset driven by `phaseElapsedSeconds / targetSeconds`, already tracked in `MeasurementSessionViewModel`). Perimeter Trace = SVG stroke-dashoffset tied to progress (maps to SwiftUI `Shape.trim(from:to:)`). ECG Sweep's waveform scroll stays ambient/continuous by design — only its progress rail is progress-driven.
